# Participation Prediction Model

## Research Context

The research incorporates a predictive analysis component based on Artificial Intelligence to analyze the participation behavior of families enrolled in the Source Segregation and Selective Collection Program in Amarilis, Huánuco.

The predictive component is intended to support the identification of participation patterns, detect families at risk of abandoning the program, and support evidence-based decision-making.

## Participation Index

The study defines a Participation Index (PI) based on three behavioral indicators:

- **F** = Participation frequency
- **C** = Quantity of recyclable waste delivered
- **T** = Time without participation

The Participation Index is defined as:

\[
PI = 0.4F + 0.3C - 0.3T
\]

## User Classification

Based on the Participation Index, participants are classified into three behavioral categories:

| Participation Index | Classification | Interpretation |
|---|---|---|
| High | Active user | Regular participation in the program |
| Medium | At-risk user | Reduced or irregular participation |
| Low | Inactive user | Little or no recent participation |

## Predictive Purpose

The predictive component is designed to:

1. Identify participation patterns.
2. Detect users at risk of abandoning the program.
3. Classify users according to their participation behavior.
4. Generate information that can support preventive interventions.
5. Improve decision-making in the municipal solid waste management program.

## Data Sources

The predictive analysis can use information generated by the intelligent system, including:

- QR-based identification records.
- Participation frequency.
- Quantity of recyclable waste delivered.
- Time since the last participation.
- Historical participation records.

## Machine Learning Perspective

The predictive component is considered a Machine Learning-oriented analysis because it uses historical participation data to identify behavioral patterns and support predictions about future participation.

The current research documentation does not specify a particular regression algorithm. Therefore, regression models should not be interpreted as part of the implemented methodology unless they are explicitly incorporated and validated in a subsequent experimental stage.

## Reproducibility

The predictive analysis should be implemented using reproducible data-processing procedures. The data preparation, feature construction, model training, evaluation, and classification results should be documented in the corresponding research notebooks.

## Research Scope

The predictive model is a decision-support component of the intelligent QR-based waste management system. It is intended to complement the monitoring and reporting functions of the system by providing analytical information about participant behavior.
