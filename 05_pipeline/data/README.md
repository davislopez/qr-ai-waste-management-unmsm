# Research Dataset

## Solid Waste Management Household Survey Dataset

This directory contains the data resources used for the analysis of the doctoral research project:

**"Intelligent System Based on Quick Response Codes and Artificial Intelligence for the Optimization of Solid Waste Management in Amarilis, Huánuco – 2026."**

### Data source

The dataset is based on information collected from families participating in the Source Segregation and Selective Collection Program in the district of Amarilis, Huánuco.

### Data collection instrument

The research instrument is a structured questionnaire consisting of **26 Likert-scale questions**.

The questionnaire evaluates two main variables:

1. **Intelligent System Based on Quick Response Code and Artificial Intelligence**
2. **Solid Waste Management**

### Measurement scale

| Value | Meaning |
|---:|---|
| 1 | Never |
| 2 | Almost never |
| 3 | Sometimes |
| 4 | Almost always |
| 5 | Always |

### Data structure

The research dataset is organized into the following groups:

- Respondent identification
- Age
- Sex
- Participation time in the program
- Sector or zone
- Items Q1–Q14: Intelligent System
- Items Q15–Q26: Solid Waste Management
- Dimension-level scores
- Variable-level scores

### Reproducibility note

The current analysis notebook reproduces the aggregated results reported in Chapter IV of the thesis. It does not claim to reconstruct individual-level responses when those raw observations are not available in the repository.

### Privacy and confidentiality

Individual personal information is not published in this repository. The repository is intended to document the research methodology, analysis process, and reproducibility of the reported results.
