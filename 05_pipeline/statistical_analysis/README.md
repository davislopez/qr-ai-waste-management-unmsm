# Statistical Analysis

## Research Project

**Title:**

Effect of the implementation of an intelligent system based on Quick Response Codes and Artificial Intelligence on the improvement of solid waste management among families participating in the Source Segregation Program in Amarilis, Huánuco – 2026.

## Purpose

This section documents the statistical analysis procedures planned for the research project.

The statistical analysis is intended to evaluate the changes observed before and after the implementation of the intelligent system based on QR Codes and Artificial Intelligence.

## Statistical Software

The data analysis will be performed using **IBM SPSS Statistics**.

Python and Google Colab may also be used to organize reported results and generate reproducible tables and visualizations.

## Data Analysis

The statistical analysis includes:

- Descriptive statistics
- Frequency distributions
- Percentages
- Mean values
- Standard deviation
- Tables
- Graphical representations
- Reliability analysis using Cronbach's Alpha
- Pretest and posttest comparison
- Hypothesis testing

## Research Design

The study uses a quasi-experimental design with pretest and posttest measurements:

G O1 X O2

Where:

- **G** = Study group
- **O1** = Pretest measurement
- **X** = Implementation of the intelligent system
- **O2** = Posttest measurement

## Variables

### Independent Variable

**Intelligent system based on Quick Response Code and Artificial Intelligence**

Main dimensions:

1. Digital registration of families
2. Identification through QR Code
3. Real-time monitoring
4. Report generation
5. Artificial Intelligence component

### Dependent Variable

**Solid waste management**

Main dimensions:

1. Family participation
2. Amount of segregated waste
3. Participation frequency
4. Program control and monitoring

## Measurement Instrument

The research instrument is a structured questionnaire containing **26 items**.

The questionnaire uses a five-point Likert scale:

| Value | Meaning |
|---|---|
| 1 | Never |
| 2 | Almost never |
| 3 | Sometimes |
| 4 | Almost always |
| 5 | Always |

## Reliability

The internal consistency of the questionnaire will be evaluated using **Cronbach's Alpha**.

The reliability analysis will be conducted using SPSS based on the responses obtained during the pilot/application stage.

## Pretest and Posttest

The pretest measurement represents the situation before the implementation of the intelligent system.

The posttest measurement represents the situation after the implementation.

The comparison between both measurements will be used to evaluate the observed changes in solid waste management.

## Hypothesis Testing

The research includes a general hypothesis and specific hypotheses concerning:

- Family participation
- Amount of segregated waste
- Participation frequency
- The Artificial Intelligence component

The appropriate inferential statistical procedure will be selected according to the characteristics and distribution of the collected data.

## Data Integrity

The analysis must be based on the actual observations collected during the research.

No synthetic observations should be presented as original questionnaire responses.

Any reconstructed or aggregated dataset used for demonstration or reproducibility must be explicitly identified as such.

## Reproducibility

The statistical analysis files, scripts, notebooks, tables, and visualizations are organized to facilitate verification and reproducibility of the analytical process.
